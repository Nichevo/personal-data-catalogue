Personal data catalogue for Windows (no install needed)

1. Unzip this folder anywhere you can write to, such as Documents.
2. Double-click "Start catalogue". The first start takes a minute.
3. Your browser opens the catalogue. The "Get started" page walks you through
   adding SQL Servers, Python projects and data folders.

To scan SQL Server, Windows needs Microsoft's "ODBC Driver 18 for SQL Server".
The Get started page says whether it's installed; if not, ask IT to install it.

Your catalogue and settings live in %USERPROFILE%\.pdcat, not in this folder.
To update, unzip the new version and use its "Start catalogue" instead; your
catalogue carries over. Close the black window to stop the catalogue.
